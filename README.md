# SBL Newsletter editor — 데스크톱 앱 내려받기

이 저장소에는 **설치 파일만** 올라갑니다 (소스 코드는 없습니다).
최신 버전은 [Releases](../../releases/latest) 에서 받으세요.

| 컴퓨터 | 파일 |
| --- | --- |
| Mac (Apple 칩: M1·M2·M3·M4…) | `SBL-Newsletter-editor-mac-arm64.dmg` |
| Mac (Intel) | `SBL-Newsletter-editor-mac-x64.dmg` |
| Windows | `SBL-Newsletter-editor-win-setup.exe` |

- **Windows**: 새 버전이 나오면 앱을 켤 때 알려 주고, [지금 업데이트]를 누르면 자동으로 설치됩니다.
- **Mac**: 새 버전이 나오면 앱을 켤 때 알려 주고, [내려받기]로 받은 .dmg 를 열어 응용 프로그램 폴더에 덮어 넣으면 됩니다.
- 처음 열 때 "확인되지 않은 개발자"(Mac) / "Windows의 PC 보호"(Windows) 경고가 나오면:
  - Mac: 앱을 **오른쪽 클릭 → 열기**, 또는 시스템 설정 › 개인정보 보호 및 보안 › **그래도 열기**
  - Windows: **추가 정보 → 실행**
- 작업 내용은 각자 컴퓨터에만 저장됩니다. 웹 버전에서 옮기려면 웹 ⚙ Settings › Backup › [작업 내보내기] 후 앱에서 [작업 가져오기].
